# WITCHBORN — playable prototype
Godot 4 project. This is an early combat sandbox, not a finished game or APK.

## Included
- Dark forest arena with diamond/isometric-style floor.
- Witch player character and pursuing enemies.
- Nature area spell and targeted blood strike.
- Health, mana, enemy health bars and kill counter.
- Touch controls: drag on the left half to move; tap upper-right for Nature and lower-right for Blood.
- Desktop controls: WASD/arrow keys, 1 = Nature, 2 = Blood.

## Run
Open this folder in Godot 4.x and press Play. Android export still requires Godot Android export templates plus Android SDK/JDK configuration and device testing.
