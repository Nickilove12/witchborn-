# WITCHBORN — Titan Quest: Anniversary Edition Mod

WITCHBORN is a mod project for **Titan Quest: Anniversary Edition**. The goal is to rebuild the existing Nature mastery and develop original Witchborn masteries while preserving the game's two-mastery character limit.

## Current design
- **Nature:** locust swarm, poison, spores, roots, strangling vines, and mobile plant companions.
- **Blood Magic:** bleeding, life drain, blood projectiles, self-sacrifice, plague, blood nova, blood tentacles, and a mobile blood golem.
- Full skill specifications and 22-node skill maps are documented in the Markdown files in this repository.
- Darkness is planned as another selectable mastery path; characters still choose no more than two masteries.

## Important status
The repository also contains an early Godot combat prototype from an earlier direction. It is **not** the Titan Quest mod and is not an installable TQAE package.

The TQAE mod still requires implementation in the game's database/Art Manager resources, followed by an actual in-game build and test. No finished mod or verified installer is claimed yet.

See `TQAE_MOD_PLAN.md` for the implementation checklist.
