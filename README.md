# WITCHBORN — Titan Quest: Anniversary Edition Mod

WITCHBORN is a mod project for **Titan Quest: Anniversary Edition**. The target is to rebuild the existing Nature mastery with original Witchborn skills and, where supported by TQAE's data structure, add Blood Magic as a separate mastery while preserving the normal two-mastery system.

## Current design
- Nature mastery: locust swarm, poison, spores, roots, strangling vines, living bark, and mobile plant companions.
- Thorn Sprouts: up to three small mobile ranged companions.
- Thorn Stalkers: up to three hip-high carnivorous plant companions with thorn projectiles and bite attacks.
- The complete Nature specification is in `NATURE_MASTERY_DRAFT.md`.

## Important status
The repository also contains an early Godot combat prototype from an earlier direction. It is **not** the Titan Quest mod and is not an installable TQAE package.

The TQAE mod still requires implementation in the game's database/Art Manager resources, followed by an actual in-game build and test. No finished mod or verified installer is claimed yet.

See `TQAE_MOD_PLAN.md` for the implementation checklist.
